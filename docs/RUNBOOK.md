# JARVIS Runbook

## First Run

1. Review HOW-TO.md.
2. Copy the sample environment file to a local environment file.
3. Fill in local configuration values.
4. Install dependencies.
5. Start the app in full mode.
6. Open the local web interface.

## Daily Run

1. Start Ollama if using local models.
2. Start JARVIS.
3. Confirm the browser UI loads.
4. Confirm the Chrome extension shows connected.
5. Confirm voice input and output work.

## Maintenance

- Pull updates from your fork regularly.
- Review dependency updates before applying them.
- Run tests after changing backend files.
- Keep local data backed up.
